YUNAMAKI3 / DOTFILES

WezTerm & LazyVim
セットアップガイド

macOS・Windows/WSLで、同じ見た目と操作感を使うための手順です。上から順番に進めれば大丈夫です。

1

macOSのバージョンを確認

Homebrewの現行版はmacOS Sonoma 14以降を正式サポートしています。最初に現在のバージョンを確認します。

sw_vers -productVersion

表示された先頭の数字が14未満の場合は、先にmacOSを更新するか、導入方法を調整する必要があります。

2

開発用ツールをインストール

GitやHomebrewの準備に必要です。次のコマンドを実行するとAppleのインストール画面が開きます。

xcode-select --install

表示された画面でインストールを完了し、次で確認します。

xcode-select -p

/Library/Developer/CommandLineTools などのパスが表示されれば準備完了です。

3

Homebrewをインストール

brew: command not found は、Homebrewが未導入という意味です。公式のコマンドを実行してください。途中でMacのログインパスワードを求められることがあります。

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

このMacはIntelモデルなので、通常は /usr/local に入ります。インストール後に新しいターミナルを開き、確認します。

brew --version

まだ見つからない場合は、Homebrewのインストール完了画面に表示された「Next steps」のコマンドをそのまま実行してください。

4

開発ツールとフォントを導入

brew install neovim starship ripgrep fd fzf llvm node
brew install --cask font-fira-mono-nerd-font font-noto-sans-cjk

英数字とアイコンにはFiraMono Nerd Font Mono、日本語にはNoto Sans Mono CJK JPを使用します。

5

dotfilesを取得して適用

GitHubへの初期ファイル反映が完了した後、次のコマンドで取得できます。

git clone https://github.com/yunamaki3/dotfiles.git ~/dotfiles cd ~/dotfiles ./scripts/setup-macos.sh

WezTermを再起動し、nvim を実行します。最初の起動時だけLazyVimのプラグイン取得に少し時間がかかります。

困ったとき

  • brew: command not found：手順3を完了し、新しいターミナルを開く。
  • git が使えない：手順2のCommand Line Toolsを完了する。
  • 文字やアイコンが崩れる：手順4のフォントを入れ、WezTermを完全に再起動する。
  • LazyVimが起動しない：nvim --version でNeovim 0.11以降か確認する。
