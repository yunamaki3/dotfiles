1. このdotfilesの構成

  • WezTerm：半透明のターミナル、ペイン分割、タブ操作、全画面切替
  • Starship：現在のディレクトリ、Gitブランチ、変更状態、言語バージョンの表示
  • LazyVim：C、Markdown、JSON、TypeScript、Tailwind CSS向けのNeovim環境
  • セットアップスクリプト：設定ファイルを所定の場所へリンクし、既存設定をバックアップ

2. macOSへの導入

2-1. Command Line Tools

xcode-select --install

2-2. Homebrewと必要なソフト

Homebrewがない場合は、Homebrew公式サイトの手順で導入します。その後、次を実行します。

brew install neovim starship ripgrep fd fzf llvm node brew install --cask font-fira-mono-nerd-font font-noto-sans-cjk

2-3. dotfilesを取得して適用

git clone https://github.com/yunamaki3/dotfiles.git ~/dotfiles cd ~/dotfiles ./scripts/setup-macos.sh

既存の通常ファイルは ~/.dotfiles-backup/日時 へ退避されます。適用後はWezTermを完全に終了して再起動してください。

3. Windows・WSLへの導入

3-1. Windows側

winget install wez.wezterm powershell -ExecutionPolicy Bypass -File .\scripts\setup-windows.ps1

FiraMono Nerd Font Mono と Noto Sans Mono CJK JP もWindowsへインストールします。

3-2. WSL側

Neovim 0.11以降、Git、Clang、ripgrep、fd、Node.js、Starshipを導入し、リポジトリ内で実行します。

./scripts/setup-wsl.sh

4. GitHubから設定を更新する

実際に使用しているリポジトリで、次を実行します。

cd ~/dotfiles git pull origin main

設定はリポジトリへシンボリックリンクされているため、通常はセットアップスクリプトの再実行は不要です。

  • WezTerm設定の再読込：Leader → r
  • Starship・シェル設定の再読込：exec zsh
  • Neovim設定の反映：Neovimを終了して再起動

5. Leaderキーの押し方

Leaderキーはショートカットの入口です。Leaderを押して離し、1.5秒以内に次のキーを押します。2つの操作は同時押しではありません。

環境Leaderキー例
WezTerm / macOSOption + Q全画面：Leaderの後に f
WezTerm / WindowsCtrl + Q全画面：Leaderの後に f
LazyVimSpaceC実行：Space → c → r

6. WezTermキーバインド

全画面表示：タイトルバーがなくても Leader → f で全画面のオン・オフを切り替えられます。WezTerm標準の Alt + Enter も使用できます。

Leaderの後に押すキー操作補足
f全画面表示を切り替えるもう一度押すと元へ戻る
v左右にペイン分割画面を縦線で分ける
s上下にペイン分割画面を横線で分ける
h / j / k / l左 / 下 / 上 / 右へ移動Vimと同じ方向
H / J / K / Lペインを左 / 下 / 上 / 右へ拡縮Shiftを使った大文字
c新しいタブを作る現在と同じドメインで開く
n / p次 / 前のタブへ移動next / previous
x現在のペインを閉じる確認画面が表示される
z現在のペインを拡大・復元分割状態は保持される
[コピーモードを開始キーボードで履歴を選択
r設定を再読み込みLua変更後に使用
qコマンドパレットを開く利用可能な操作を検索

7. コピーモード

Leader → [ で開始し、次のキーで操作します。

キー操作
h / j / k / l左 / 下 / 上 / 右へカーソル移動
w / b次 / 前の単語へ移動
0 / $行頭 / 行末へ移動
g / Gスクロール履歴の先頭 / 末尾へ移動
v / V文字単位 / 行単位の選択を開始
y選択範囲をクリップボードへコピーして終了
Esc / qコピーせず終了

8. Neovim・LazyVim

操作役割
:Lazyプラグインの状態確認・更新
:MasonLSP、フォーマッター、外部ツールの確認
:checkhealthNeovim環境の問題を診断
Space → c → rCファイルを保存、厳格な警告付きでコンパイル、実行

初回起動ではLazyVimのプラグインとMasonのツール取得に時間がかかります。処理中はNeovimを閉じず、完了後に一度再起動してください。

9. トラブル対応

症状確認・対処
タイトルバーがなく全画面にできないLeader → f。または Alt + Enter
設定変更が反映されないgit pull 後、WezTermは Leader → r、シェルは exec zsh
アイコンが四角や文字化けになるNerd Fontを導入し、WezTermを完全に再起動
Package is already installing初回インストールの完了を待ち、Neovimを終了して再起動
LazyVimが起動しないnvim --version と :checkhealth を確認。Neovim 0.11以降を使用
変更をpullできないgit status でローカル変更を確認。消してよいか不明な変更は削除しない
外部CSSや外部JavaScriptを使わない、単一HTMLファイルです。ブラウザで直接開いて閲覧・印刷できます。
